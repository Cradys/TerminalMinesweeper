# Minesweeper

Консольний Сапер на TypeScript, що працює прямо в терміналі.
```
[#][#][1][ ][ ][1][#][#][#]
[#][#][1][ ][ ][1][⚑][#][#]
[#][2][1][ ][ ][1][2][#][#]
[#]█#█[1][1][1][ ][1][#][#]

Flags left (mines): 9

↑↓←→ - Move   Enter/Space - Open   f - Flag   q - Quit
```

## Запуск

Потрібен Node.js і справжній термінал (гра вмикає raw-режим, тому не працює з перенаправленим вводом).

```bash
npm install
npm start
```

> Для гри використовуй `npm start`, а не `npm run dev`. `tsx watch` перезапускає програму, коли в stdin надходять будь-які дані, тож кожне натискання клавіші починало б гру заново.

## Керування

| Клавіша | Меню | Гра | Кінець гри |
|---|---|---|---|
| `↑` `↓` | вибір рівня | рух курсора | — |
| `←` `→` | — | рух курсора | — |
| `Enter` / `Space` | почати гру | відкрити клітинку | — |
| `f` | — | поставити / зняти прапорець | — |
| `r` | — | — | повернутися в меню |
| `q` / `Ctrl+C` | вихід | вихід | вихід |

Клавіші розпізнаються за символом, тож для `f`, `r` і `q` має бути увімкнена англійська розкладка.

## Рівні складності

| Рівень | Поле | Міни |
|---|---|---|
| easy | 9 × 9 | 10 |
| medium | 16 × 16 | 40 |
| hard | 16 × 30 | 99 |

Поле `hard` займає 90 колонок, тому вікно терміналу має бути досить широким.

## Позначення на полі

| Символ | Значення |
|---|---|
| `#` | закрита клітинка |
| ` ` | відкрита клітинка без мін навколо |
| `1`–`8` | кількість мін серед сусідніх клітинок |
| `⚑` | прапорець |
| `●` | міна |
| `X` | прапорець стояв не на міні (показується в кінці гри) |
| `█ █` | клітинка під курсором |

Для `⚑` і `●` потрібен шрифт із цими символами. Якщо замість них видно порожні квадрати, зміни шрифт терміналу або символи у `findCellSymbol` у [src/terminal.ts](src/terminal.ts).

## Структура

```
src/
├── index.ts      точка входу: створює Game
├── game.ts       Game — стани гри (menu → playing → over), обробка команд, рівні, підказки футера
├── grid.ts       Grid — поле: розстановка мін, зв'язування сусідів, прапорці, перевірка перемоги
├── cell.ts       Cell — клітинка: міна чи число, відкриття із заливкою порожніх областей
├── terminal.ts   Terminal — raw-режим, переклад клавіш у команди, малювання екранів
└── types.ts      спільні типи
```

Залежності йдуть в один бік:

- `Cell` і `Grid` — модель. Вони нічого не знають ні про термінал, ні про гру.
- `Terminal` малює те, що йому передали, і повідомляє про натиснуті клавіші через колбек. Про `Game` він не знає.
- `Game` з'єднує модель і термінал: зберігає стан, вирішує, що робить кожна команда, і просить термінал перемалювати екран.
